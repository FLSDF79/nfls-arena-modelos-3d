# nfls-arena-modelos-3d

Repositório dos modelos 3D didáticos da NFLS AI ARENA. Conceitos abertos para explicar.

Página do repositório: https://github.com/FLSDF79/nfls-arena-modelos-3d

Cada arquivo pode ser baixado direto, sem clonar o repositório, neste padrão:

https://raw.githubusercontent.com/FLSDF79/nfls-arena-modelos-3d/main/NOME

Troque NOME pelo nome do arquivo. Exemplo: https://raw.githubusercontent.com/FLSDF79/nfls-arena-modelos-3d/main/indice.json

O índice fica em indice.json. Ele lista os 31 conceitos, com ordem, id, título e o nome do arquivo de cada um.

Cada JSON numerado é um conceito só. Vai de 01-personnel-11.json até 31-mesh.json. Em cada arquivo estão o texto para explicar, a câmera, os tempos e o caminho das peças.

O pacote com os 31 conceitos juntos está em modelos-3d.json.

O arquivo LEIA-ME-modelos-3d.txt já está neste repositório. Ele explica a leitura do campo: x 0 é o centro, y 0 é a linha de scrimmage, e o diagrama é didático, não tracking.
